# Banco Topo

Demo educativa de home banking construida con React y Vite. El inicio de sesión,
el saldo, las transferencias y las inversiones son simulados: no se conecta a un
banco ni se mueve o invierte dinero real. No ingreses datos bancarios reales.

## Requisitos

- Node.js 18 o superior
- npm

## Empezar

```bash
npm install
npm run dev
```

Para generar una compilación de producción, ejecutá `npm run build`.

La aplicación se publica automáticamente en GitHub Pages al subir cambios a
`main`: https://cheibeck.github.io/ProjectBank/
